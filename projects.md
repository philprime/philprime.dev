I build software for developers and the people who use their products. Here's a collection of the apps, libraries, infrastructure projects, and tools I'm working on or have helped build.

### Services and apps

- **[philprime.dev](https://philprime.dev)** – Technical guides and articles about software development and infrastructure.
- **[appmetadata.com](https://appmetadata.com)** – An API for searching and fetching public App Store metadata.
- **[shipable.dev](https://shipable.dev)** – A platform for building and shipping mobile apps at scale.
- **[Flinky](https://github.com/techprimate/Flinky)** – An open-source iOS app for organizing and sharing links in person.
- **[flinky.me](https://flinky.me)** – A landing page for Flinky, powered by appmetadata.com.

### Work at Sentry

As a senior software engineer at Sentry, I contribute to the tools developers use to understand and fix issues in their apps.

- **[Sentry Apple SDK](https://github.com/getsentry/sentry-cocoa)** – Error monitoring and performance tools for Apple's platforms.
- **[Sentry documentation](https://github.com/getsentry/sentry-docs)** – Guides and reference material for integrating Sentry.
- **[Sentry fastlane plugin](https://github.com/getsentry/sentry-fastlane-plugin)** – A fastlane plugin for integrating Sentry into app release workflows.

### Frameworks and libraries

- **[go-health](https://github.com/kula-app/go-health)** – A Go library for standardized HTTP health-check endpoints.
- **[Postie](https://github.com/kula-app/Postie)** – Structured HTTP API clients in Swift.
- **[TPPDF](https://github.com/techprimate/TPPDF)** – A PDF generation framework for iOS and macOS.
- **[Twill](https://github.com/philprime/Twill)** – A Swift library for interactive terminal user interfaces.

### Infrastructure

- **[iris](https://github.com/philprime/iris)** – A Kubernetes controller that routes and processes inbound email for in-cluster services.
- **[gha-runner-autoscaler-controller](https://github.com/kula-app/gha-runner-autoscaler-controller)** – A Kubernetes controller that adjusts GitHub Actions runner capacity to available cluster resources.

### Developer tools

- **[diagnostics-action](https://github.com/philprime/diagnostics-action)** – Container-free CI diagnostics for macOS and Linux.
- **[renovate-validator-action](https://github.com/philprime/renovate-validator-action)** – A GitHub Action that validates `renovate.json` and skips repositories without it.
- **[wait-for-services-action](https://github.com/kula-app/wait-for-services-action)** – A GitHub Action that waits for services to be ready.
- **[clean-cache-action](https://github.com/kula-app/clean-cache-action)** – A GitHub Action for clearing stale Actions caches.
- **[has-changed-path](https://github.com/kula-app/has-changed-path)** – A GitHub Action for detecting changed paths in pull requests.
- **[github-actions-utils-cli](https://github.com/techprimate/github-actions-utils-cli)** – An experimental CLI for working with GitHub Actions.
- **[ship](https://github.com/kula-app/ship)** – A CLI for working with shipable.dev.
- **[kula-app/containers](https://github.com/kula-app/containers)** – Reusable container images for deployment and CI/CD.
- **[objc-msg-analyzer](https://github.com/philprime/objc-msg-analyzer)** – A Swift tool for analyzing Objective-C message sends.
- **[apple-docs-cli](https://github.com/techprimate/apple-docs-cli)** – A CLI for browsing and searching Apple Developer documentation.

Find more of my work on [GitHub](https://github.com/philprime), or [get in touch](https://www.linkedin.com/in/philipniedertscheider/) if you'd like to collaborate.
